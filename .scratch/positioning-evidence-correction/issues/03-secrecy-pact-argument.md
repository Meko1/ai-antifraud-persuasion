# 03: 把「骗子的保密协议」写进核心论证

**What to build:** 读者读到"为什么是角色对调，不是又一个风险提示弹窗"这一节时，看到的不再只是一个心理学推断，而是一条可查证的外部事实：这类骗局会要求受害者签保密协议，**明确禁止向证券公司、监管部门、公安机关透露任何信息**。这一条直接废掉法定工具箱里的"核实交易情况／重新核验身份"——受害者已经被预先训练成会撒谎——而"去劝另一个人"不要求任何披露、不要求任何承认，是这套预设防御唯一绕得开的形态。

这是这个定位最强的一个论点，目前在仓库里一个字都没有。
