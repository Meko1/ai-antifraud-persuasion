## 起因

上一轮把难度做上去之后（expert 98.7% → 47.9%），暴露了两个新问题：

1. **可玩性不足以吸引投票。** 路人打不动。
2. **选题是否符合大赛方向存疑。**（AI 创想家大赛，方向建议"泛财经类应用"）

访谈结论是：这两个问题有同一个解——**产品定位错了，它不是游戏**。

## 大赛的硬事实

| 项 | 值 | 推论 |
|---|---|---|
| 投票机制 | 每人 10 票，单作品最多 2 票 | **非零和**。投你一票的机会成本近乎为零，竞争的是"被看见"而非"击败对手" |
| 关键窗口 | 9/03 投票启动 → 9/21 投稿截止 | 18 天，触达广度是胜负手 |
| 赛道 | 泛财经类应用 / 让 AI 成为职场加速器 | 训练器定位正中赛道，游戏定位是擦边 |

## 三个调研发现

### 一、现存反诈互动产品全都是脚本化的

| 产品 | 机构 | 形态 |
|---|---|---|
| 尊嘟假嘟 | 腾讯互娱 × 广东反诈中心 | 聊天界面**选项判断** |
| 反诈剧本杀 | 银河证券 / 深圳裕丰社 | 线下脚本 |
| 《相亲话防非》《方小牛防骗课堂》 | 方正证券 | 真人剧 / 动画 |
| 当案馆沉浸式防骗展 | 国家反诈中心 × 支付宝 | 线下展陈 |

**没有一个的受害者是活的。** 我们唯一无法被复制的资产是——**老陈会反驳你，
会用你没预料到的话堵你**。这是全场唯一一个"必须有 LLM 才成立"的反诈产品。

> **推论（重要）**：曾考虑过的"每轮给 3 个候选句点选"方案**已否决**。它会让作品
> 和一个 2024 年的腾讯公益 H5 长得一模一样，主动放弃唯一的差异点。
> 自由文本输入是不可让渡的。

### 二、我们的分享卡分享错了东西

Character.AI 增长 64% 来自口碑，而**人们分享的是 AI 说的话的截图（名场面），
不是自己的成绩**。我们现在的分享卡是 K 线 + 轮次 + 信任度峰值——一张成绩单。

真正的社交货币是这类句子：

> 免责协议那是行规，你外行不懂。

一个东财人看到会心头一紧，**因为他上周刚听客户说过差不多的话**。

### 三、这是公司的业务痛点，不是游戏题材

券商投顾的真实合规痛点里排第一的是：

> **客户处于沉没成本状态时极难劝回。** 骗子用"行情到最后关头了""补仓摊薄成本"
> 拖住客户，最后拉黑失联。

这就是老陈。另有一条硬约束：**投顾说话本身是高风险动作**——多家券商因投顾
无证荐股/微信群给建议被罚。所以合规话术必须与"荐股"严格切割：**只能问，不能荐**。

而判分引擎恰好就是这么设计的：三把钥匙全是"问"（锚定用途、苏格拉底提问、
指出矛盾），三项失误全是"说"（责骂、说教、空口断言）。**这不是巧合，是对的
方法论，但现在没人看得出来。**

## 已决策

### D1 · 定位：训练器，保留游戏的皮

> **2026-08-15 落地。** D1 写完之后有三个月对外主张是投顾训练器、虚构设定却还停在
> "同群的陌生人"——判分引擎照投顾写（三把钥匙全是"问"），故事没让玩家当投顾。
> 症状是"我为什么要劝他"答不上来，且首页六条会话与聊天页互相矛盾（那是老陈的手机，
> 却让老陈给自己发消息）。八条决策与改动面见 CONTEXT.md「两个人」与 TECH-DESIGN §1、§8.1。

对外主张从"一个反诈小游戏"改为"**客户被荐股骗局套住时，投顾该怎么开口**"的
可交互训练器。同事投票不需要"好玩"，需要"**有用 + 认得出**"。

**风险**：训练器定位会抬高对专业性的期待。剧本与判分标准需要用真实业务判断
校一遍——**这部分必须由项目所有者完成，不可由 AI 代劳**。

### D2 · 双入口：对局 + 接话

真实的话术训练从来不是打完一整局，而是针对单个异议反复练应对
（objection handling drill）。

| | 接话 | 对局 |
|---|---|---|
| 时长 | **15 秒** | 3–4 分钟 |
| 内容 | 老陈抛一条真实异议，你回一句 | 现在这个 12 轮 |
| 对谁 | 路人（投票主力）、投顾日常刷 | 想认真打的人、评审 |
| 判分 | **可以亮**（单句不构成攻略） | 藏到复盘（维持上一轮的决策） |
| 传播单元 | **那条异议本身** | 分层结局卡 |

**默认入口是接话。** 微信会话列表那一屏保留（全作品最好的一处设计，六条会话
把整个故事讲完了）；点进老陈后默认落在接话，"接着劝下去（还有十一轮）"作为
升级路径。**投票转化不再依赖打完整局，深度资产一分没少。**

**领域模型上，接话与对局是两件不同的事，不是同一件事的两种模式**——见 D5。

### D3 · 结局改为四档阶梯

现在 87% 的玩家拿到的分享卡标题是"他还是转走了"。**没有人会把失败截图发到群里**，
病毒循环在源头就断了。

| 档 | 结局 | 他做了什么 |
|---|---|---|
| 1 | **劝住** | 一分没转 |
| 2 | **拦下** | 只转出一小笔试水，绝大部分保住了 |
| 3 | **拖住** | 把转账推迟，钱没动也没保住 |
| 4 | **转账** | 全部转出 |
| — | **被拉黑** | 提前出局，不入档 |

**判分引擎一行不动**，改的只是结局呈现层。难度、效力矩阵、防御姿态、追问窗口
全部原样保留。

阶梯量的是"他有多信你"，对玩家呈现为"你救回了多少钱"（金额是东财人的母语）。
排序有一处反直觉已在 CONTEXT.md 中记录：拖住排在拦下之下，因为"我再想想"
多半是打发人的话，不是让步。

**已确认保留的残酷之处**："拦下"档里仍有一小笔钱被转走。它在业务上真实
（骗局标准剧本就是"先小额取信"），代价是玩家表现不错、结局仍有人损失。
**取真实。**

### D4 · 揭晓给三样东西，先答后揭

先提交自己的答案（此时无从抄袭），提交后才揭晓：

| | 内容 | 作用 |
|---|---|---|
| **你的** | 你那句 + 老陈的真实反应 + 得分 | 即时反馈 |
| **一个高分答法** | 不叫"标准答案"，叫"有人这么接" + 点出用的哪把钥匙、为什么此时管用 | 教学价值 |
| **最常见的错误答法** | 从 Redis 挖真实数据："X% 的人第一反应是说『这是诈骗』——老陈平均掉 N 分" | 社交证明 |

第三样顺手激活了 `app/stats.py`——**那套 Redis 统计写好了但前端从没调用过**。
这个数字自己会长，参与的人越多越有说服力。

**关于"泄漏攻略"**：单句训练明示方法论、12 轮对局什么都不给，是刻意分工
（练习册有答案，考试没有）。且示范答案被原样抄进对局只值 0.45 倍——
`UNGROUNDED_FACTOR` 从第一天起就在防这个（§9.2：关掉它 parrot 胜率 2% → 75%）。
**示范答案可以放心亮。**

### D5 · 领域语言（已写入 CONTEXT.md）

新增：**接话 / 异议 / 揭晓**，以及结局四档 **劝住 / 拦下 / 拖住 / 转账**。

两处推敲留痕，避免后人重蹈：

- **"拆招""过招"已否决**——`劝阻对象` 的定义写着"他是被劝的人，**不是对手**"，
  武术词把他框成了对手，与整套语言的立场冲突。改用"接话"，取自现实里那句
  "客户这么说，你怎么接"。
- **接话不是"长度为 1 的对局"**。信任度、防御姿态、追问窗口只在连续十二轮里
  才有意义；问"接话的初始信任度是多少"是没有意义的，那是模型套错了的信号。
  接话应走独立的无状态路径，不必复用 `GameState`。

## 未决——需要项目所有者的业务判断，不可由 AI 代答

1. **"异议"是否是东方财富内部的说法。** 现在这个词是从行业资料里借的
   （objection handling）。如果公司内部对客户挡箭牌有现成叫法，**用你们的**。
2. **异议题库从哪来。** 需要 15–25 条，覆盖沉没成本、从众、权威、时间压力、
   防御性攻击几类。是凭业务经验写，还是从真实案例话术
   （"补仓摊薄成本""资金被冻结需缴解冻保证金"那类）提炼？
   **这是全案最重的内容工作量，也是专业性的上限所在。**
3. **每条异议的示范答法与"为什么管用"**（15–25 组）。同上，必须人写。
4. **"拖住"与"拦下"的排序**。若实务上"只要拖过当天营业部就能介入"，
   则阶梯应反过来。现有排序基于二手资料。

### 第 1–2 步的落地记录（2026-08-15）

- **分档不引入新阈值**：12 轮打完落哪一档，直接取他最后停在的情绪档位
  （松动→拦下，动摇→拖住，烦躁/戒备→转账）。档位本来就是"他有多信你"的分层，
  阶梯量的是同一件事，再拍两个数字只会多两个要标定的参数。已并入 TECH-DESIGN §2.2。
- **改档后的分布**（`tools.balance_sim`，2 万局/人设，已加进门槛表与输出）：

  | | 劝住 | 拦下 | 拖住 | 转账 | 被拉黑 |
  |---|---|---|---|---|---|
  | 加权总体 | 13.3% | 15.4% | 23.8% | 42.3% | 5.2% |

  拿到最低一档的从 87% 降到 42.3%。**仍有四成多**，来源是 novice（25% 人群里
  79% 转账）与 average（55%）——他们确实没推动过老陈，给更好的档就是撒谎。
  若要再压，唯一诚实的做法是把"拖住"下探到烦躁档，那等于承认"没推动他"也算争到时间。
  **这一条留给项目所有者定，与"未决"四项一并。**
- **名场面由玩家自己挑**：复盘里列出他这一局说过的每一句（8–44 字，去重），
  默认值由一个小启发式给（长度、是否冲着"你"来、有没有骗局黑话）。
  自动挑一句"最金句"是挑不准的，而选择权本来就该在玩家手上。

### 一条别踩的坑

**不要为了让路人赢而调低难度，也不要加选项模式。** 上一轮好不容易把
expert 从 98.7% 压到 47.9%，那是评审关的核心资产。路人的转化问题由
**接话入口 + 分层结局**解决，不由降低难度解决——这两条是这次访谈的核心结论。
