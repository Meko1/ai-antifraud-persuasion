## 分类器标注集怎么用（§9.3）

改了 `CLASSIFY_SYSTEM_PROMPT` 就重跑一次，几毛钱的事：

```
.venv/bin/python -m tools.classify_eval --limit 10   # 先确认链路
.venv/bin/python -m tools.classify_eval              # 全量 + 门槛校验
```

**四道门槛**，任一不过退出码非零：`hit_keys` ≥ 85%、`grounded` 全样本 ≥ 80%、
`grounded` 有钥匙子集 ≥ 80%、**`grounded` 复读攻略子集 ≥ 93%**。

最后那道是这次做出来的关键发现，别当成可有可无的附加项：
总体 85.5% 达标的那一次，复读攻略子集只有 64%，把泄漏率代回蒙特卡洛，
**parrot 胜率从 10.9% 飙到 69.6%**——§9.4 的 20% 上限被击穿，而总体指标毫无察觉。
93% 这个数字是从平衡模型反推的，推导过程写在 §9.3 和 `PARROT_GROUNDED_FLOOR` 的注释里。

标注集自身的质量由 `tests/test_classify_eval.py` 守着（不调模型，进 CI）：
规模、闭集、难例覆盖、扎根比例、复读攻略必须标未扎根。**加标注前先看文件顶部的五条约定**，
尤其是"一条样本最多标一把钥匙"——蒙特卡洛的人设每轮最多出一把钥匙，
允许双钥匙会让单轮上限从 25 变 45，§9.4 的标定直接失效。

## 前端结构（§8）

原生 HTML/JS，零构建，三个文件。`package.sh` 已整目录打包。

- `static/index.html` — 结构（首页会话列表 + 聊天页）
- `static/style.css` — 设计令牌与全部样式
- `static/app.js` — SSE 解析、K 线绘制、复盘、分享卡

**界面语法整体照搬微信**，这是全部设计决策的根。理由不是"微信好看"——微信恰恰
极度克制——而是这类荐股骗局本来就发生在聊天软件里。玩家在这套熟悉的语法里劝阻，
等于站在事发现场，一眼就知道每个东西是干什么的，不用学，也就不需要教程。

**一切都借微信本来就有的槽位，不新造控件**：

| 游戏里的东西 | 借的是微信的 |
|---|---|
| 判分卡（±分、命中标签） | 系统提示（显示"你撤回了一条消息"的那条） |
| 对局状态（信任度、剩余轮次） | 群公告条 |
| 结局 · 转走 | 转账凭证截图，橙卡，`已被对方接收` |
| 结局 · 劝住 | 同一张卡的作废态，灰卡，金额划掉 |
| 结局 · 被拉黑 | `对方开启了朋友验证，你还不是他（她）朋友。` |

**首页那六条会话就是全部铺垫**，一句旁白都不用写：老陈（未读红点，唯一能点的）、
启航投顾群（玩家能私聊他的理由——同群才能私聊）、招商银行（他已经转过一次五万）、
老伴（这笔钱家里等着用）、小雨（**女儿劝过，而且劝失败了**）、国家反诈中心
（官方提醒他也划掉了）。第五条最要紧：玩家读完就知道"这是诈骗"四个字没用，
而这正是判分引擎里 `bare_assertion` 要扣分的原因。

开局请求在玩家读这一屏时就发出去了，点开会话时开场白通常已经到手——
「首屏 ≤3 秒」是被会话列表那一屏顺手买的单。

**只有一个颜色不属于微信**：`--gold`，专供游戏层（劝住线、复盘里最有力的那一轮）。
留一个外来色，是为了让"这是一局游戏"和"这是一次真实对话"能被一眼分开。

**视觉取自老陈自己的世界**：信任度画成红涨绿跌的 K 线（荐股群那套配色）。
一根蜡烛一轮，实体是信任度起落，细横线是判分给出的分数——两者的落差就是
每轮的信任流失与蓄势池的存取。同一个 `paintKline()` 同时服务复盘曲线与
分享卡两处，改一处两处一起变。

**SSE 走 POST**，所以不能用 `EventSource`（它只发 GET），`readEvents()` 自己解协议。
`score` 在台词播完后才到，前端据此播信任度动画——这个顺序是刻意的，别改。

## 踩过的坑（别再踩一遍）

1. **`delta` 语义**：只记判分结果，**不含信任流失**。依据是 §7.2 样例里 `d:20` 恰等于基值。
2. **取整规则**：权重相乘必出小数，实现是**求和后一次性四舍五入、对负数对称**（`_round_half_up`）。
   改这里会动摇蒙特卡洛结果，§3.5 脚注那条测试会红。
3. **兜底台词绕过安全层直发**，所以必须自身安全。`app/fallback.py` 顶部有说明，
   加词后跑一遍安全层自审。
4. **开场白必须进 session，而且要一路带下去**。它是第 1 轮唯一可供"扎根"的内容。
   曾经两次断在这儿：一次是没进 session，一次是 `play_turn` 建下一个 session 时把
   `opening` 丢了，令牌从第 1 轮之后就没有开场白了。回归测试：
   `test_开场白与历史都要送到网关手里`、`test_开场白要一路跟着令牌走`。
5. **`STATE_SIGNING_SECRET` 缺失时服务拒绝启动**。CI 里已经配了一次性值。
6. **`.env` 里有真实 API key**，已被 gitignore 和 `package.sh` 双重排除。
   比赛结束后建议轮换。
7. **判分参数不要抄进前端**。信任度初值与劝住阈值由 `/api/game/start` 下发
   （`trust` / `win_threshold`）。抄一份到 JS 里，调参时蒙特卡洛会重跑，页面上那条线不会。
8. **`unzip -Z1 ... | grep -q` 在 `set -o pipefail` 下会假失败**。`grep -q` 命中即退出，
   `unzip` 吃到 SIGPIPE 返回非零，整条流水线被判失败——匹配越靠前越容易触发。
   `package.sh` 里已改成先取清单再用 herestring。前端加文件让清单变长，这个坑就炸了。
9. **canvas 作为 flex 子项要写 `min-width: 0`**。按 dpr 放大后的固有宽度会变成
   min-content，把同一行右边的东西整个挤出屏幕。
10. **中文输入法的回车**：监听 keydown 发送时必须判 `e.isComposing`，
    否则玩家选候选词时会把半句话发出去。
11. **虚构设定与界面语法必须是同一个**。界面改成微信之后，提示词和兜底台词
    还留着打电话的说法（"喂？你哪位""说完了我要挂了""撂下一句狠话就挂断"），
    在聊天窗口里当场穿帮。已全部改成打字的说法，`app/fallback.py` 顶部加了
    警示。**加台词前先想一遍：这句话是打字打出来的，不是嘴上说的。**
12. **`requestAnimationFrame` 不能用来推进状态**。页面切到后台它就不再回调
    （`setTimeout` 也会被节流）。玩家在活动现场切出去看一眼微信是常态，回来
    会发现信任度还停在上一轮、单据没盖章、复盘曲线是空的。三处已改掉：
    数字滚动加了 `setTimeout` 兜底、盖章改用 `void el.offsetHeight` 强制回流、
    复盘曲线直接量直接画（读 `clientWidth` 本身就会强制布局）。
