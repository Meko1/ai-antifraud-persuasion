# 东方财富创想家大赛「AI反诈劝阻」改进方案

*以东方财富高管 + 证券行业产品视角，综合竞品拆解、GPT外部评审、真实用户反馈与现有项目文档撰写*

------

## 一、先说结论：这不是创意问题，是"价值到达太晚"的问题

看完前三名作品、GPT的20维评分报告（[eastmoney-contest-popularity-review.pdf](https://claude.ai/Users/meko/Documents/emc/260076/file/2026-09/eastmoney-contest-popularity-review.pdf)）、两位同事的真实体验反馈，再对照 [`docs/POSITIONING.md`](https://claude.ai/epitaxy/docs/POSITIONING.md)、[`docs/CONTEST.md`](https://claude.ai/epitaxy/docs/CONTEST.md) 和 [`static/index.html`](https://claude.ai/epitaxy/static/index.html) 里已经沉淀的产品逻辑，我的判断和GPT报告一致，也是这份材料里最值得反复念的一句话：

> **当前项目不是创意不足，而是把最强价值藏得太深。**

这个项目的核心资产——角色对调、六场景28人格、确定性判分、效力矩阵（同一句话早说晚说差一倍）——放在整个大赛里横向比较，原创性和技术含金量是三个第一名里最高的（GPT给了9/10）。但用户从点进作品到摸到这个核心资产，中间要走完"确认转出→坐到对面→查看异常记录→联系客户→知道了开始"五步操作，而这五步里没有一步在还债——用户投入的每一秒，换不回一点点即时反馈。这是致命的：投票场景的用户不是来上班的员工，是在会议间隙划两下手机的路人，前三名全部在30秒内让人"看到结果"，我们却要他先理解转账拦截、角色身份、执业红线三件事之后才轮到他说第一句话。

这不是要推翻现有设计——判分引擎、六场景、效力矩阵这些"两个月蒙特卡洛标定过"的资产一个字都不该动。要动的是**呈现顺序**，不是**内容本身**。

------

## 二、三个第一名到底赢在哪——可复用的机制，不可照搬的形式

把三份作品拆开看，赢的不是同一件事，但拼在一起正好构成一条完整的转化公式：**5秒看懂 → 30秒参与 → 1分钟拿到反馈 → 有理由回来或转发。**

| 作品                    | 五秒钩子                                                  | 本质优势                                                     | 我们能学、不能照搬的边界                                     |
| ----------------------- | --------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **第一名·听韭菜老中医** | 默认展示真实K线案例，直接给"宜买宜卖"的结论               | **结果先于过程**：不要求用户先理解算法，先给答案，专业暗色图表语言建立"这东西懂行"的第一印象 | 学它"先给结果"的顺序、学它专业深色终端的视觉语言；不能学的是它默认呈现"确定性买卖建议"——我们的产品红线之一就是"不给投资意见"，这条线不能碰 |
| **第二名·股杀**         | "杀/闪/抽/牢/斧/炸"是三国杀式的国民级游戏语法，零学习成本 | 低认知门槛 + 连续反馈：每一轮出牌立刻揭晓盈亏，15回合打完还有AI复盘、K线课堂、"再来一局" | 学它"每一步都有即时反馈"和"结束后立刻能再来一局"；**不能学**它50%概率直接终局的赌博式决胜机制——GPT报告说得很准："适合娱乐游戏，却不适合严肃反诈叙事"，随机性太强会让评委和用户误以为结果靠运气，直接稀释我们最想立住的"确定性判分"这块地基 |
| **第三名·东财茶水间**   | 一进去就是热门帖、点赞数、评论数——不需要任何金融背景      | 社会认同 + 内容循环：内容每天在变，创作者和浏览者互相供给，作品本身就是分发渠道 | 学它"让真人证据被看见"这一层意图，比如复盘页展示"目前同事里X%劝住、X%拦下"；**不能学**它往社区、工具箱方向扩张——这个项目的价值资产是一次严肃的干预，不是一个天天要回访的内容广场，硬凑热闹只会把叙事焦点冲淡 |

三个共同点，也是当前项目最缺的三样东西：**当场给结果、认知负担低、有具体可见的真人证据**。

## 三、最高杠杆的一次改动：把"同一句话，换个时候说"提前

如果只能改一件事，GPT报告和我的判断完全重合：

> 把"同一句话换个时候说，差几倍"从十轮后的复盘，提前到用户第一句话之后。

这个瞬间同时具备原创性、技术壁垒、教育价值和传播性——它是这个项目唯一一条竞品完全没有的判据（效力矩阵：同一把钥匙在不同情绪档位值不同的分），但现在被锁在整局打完之后的复盘页里，评委和路人级投票者根本走不到那一步。具体做法：

**新增一条独立的"60~90秒大赛体验局"入口，和完整十轮模式并列，不是阉割版，是把最有辨识度的一次价值证明单独拎出来**：

| 时间    | 用户看到什么                                             | 目的                                                         |
| ------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| 0–10秒  | "30万元即将转出。你只有一句话，让他停下来。"             | 立即建立任务感和风险感，跳过工作台/档案/规则页               |
| 10–40秒 | 用户自由输入一句，AI客户立即回应                         | 保留项目最强的差异化资产：**对方是活人写的回应，没有选项可选** |
| 40–60秒 | 揭晓："方向没错，但现在说只有0.6倍；他动摇之后说是1.2倍" | 把效力矩阵提前兑现，这是全场唯一的"啊哈时刻"                 |
| 60–90秒 | 继续打满十轮 / 生成一张轻量结果卡                        | 把短体验导向深度与传播                                       |

七把钥匙不该在开局当"入场考试"一次性甩给用户，应该在用户第一次表达之后逐步展开——这和已有的 [`static/keys.js`](https://claude.ai/epitaxy/static/keys.js) "识别优于回忆"的设计精神完全一致，只是把展开的时间点再往后挪一格。

**这个改动不会和已有的产品哲学冲突**，反而是同一条思路的延伸：[`docs/POSITIONING.md`](https://claude.ai/epitaxy/docs/POSITIONING.md) 里本来就规划了 Tier 0/Tier 1/Tier 2 的分级结构和"自愿进入的账户安全入口"，60~90秒体验局本质上就是 Tier 1 的一次活体原型。**这不是为了赛期临时凑一个功能，是把大赛流量顺手变成产品路线图第7步需要的第一批真实数据**——完成率、退出轮次分布这些东西，赛期内免费拿到，比事后单独申请一次灰度测试划算得多。这是我认为这份改进方案里唯一值得高管专门批一句话的地方：**把拿票的动作和拿授权的动作合并成一件事去做**。

## 四、真实反馈里的三个具体问题，怎么解

两位同事的体验反馈很扎实，值得逐条拆解，而不是笼统地说"优化体验"。

### 1. "我有点词穷"——但不能靠选择题解决

庄媛的建议是"选择题+用户自己输入"混合模式。这个建议方向是对的（降低参与焦虑），但落地方式和 [`docs/POSITIONING.md`](https://claude.ai/epitaxy/docs/POSITIONING.md) 里已经明确否决的一条红线正面冲突：

> 每轮给几个候选句点选——选项化之后作品和公益H5长得一模一样，主动放弃唯一无法被复制的资产：**劝阻对象是活的**。

这条红线不该松动，否则我们和"股杀"的差异就消失了——他们靠卡牌选择降门槛没问题，因为他们卖的是策略博弈的爽感；我们卖的是"你真的要去说服一个人"，一旦变成点选题库，这个卖点直接归零。**但"词穷"这个真实痛点必须解决，只是要换一种不牺牲自由文本的解法**：

- **primer 阶段（七把钥匙介绍屏）补一层"方向提示"，不给具体台词**：现在只给七个抽象名字（问用途、指出内部矛盾……），可以在每个名字后面加一句极短的场景化提示，比如"问用途——他刚提到那三十万要留给谁了吗？"，提示的是"往哪个方向想"，不是"该说哪句话"，这条线卡在给方向和给答案之间，不会退回选项化。
- **对局中持续没有进展时，用GPT报告P0-3的思路做非泄题反馈**：不显示分数，用"他停顿了几秒""他开始解释而不是直接反驳"这类描述性的气氛反馈，配合轻动效或触感反馈（H5端可以用Vibration API做一次短促震动），让用户感觉"我的话有落点"，而不是对着一个没有回音的黑箱打字。
- **首次进入设一次性新手引导局，不是降低expert难度**：GPT建议、同事建议里都提到"难度逐渐升级、先熟悉规则再通关"，这条要小心执行——[`docs/POSITIONING.md`](https://claude.ai/epitaxy/docs/POSITIONING.md)明确写着"不为了让路人赢而调低难度，expert从98.7%压到47.9%是评审关的核心资产"。**新手引导和降低难度是两件事**：可以给第一次进入的用户加一段一次性的、可跳过的示范（比如展示一段"扎根值2.2倍"命中的真实范例对话，而不是改判分参数），教的是"怎么玩"，不是"放水让你赢"。

### 2. "先确认转出再转换角色，确实有点绕弯子"

这条反馈指向的正是第三节说的问题——从点进作品到"被拦下"那个关键转折点，中间的操作链路太长。这条反馈里同事自己就提到"可以试试参考AI文档里面的建议"，说明这条痛点和GPT报告P0-1/P0-2指向的是同一处。**60~90秒体验局直接把这条链路压到10秒内建立任务感**，是对这条反馈最直接的回应，不需要另外单独修。完整十轮模式的链路可以保留（它服务的是愿意深度体验的用户），但不该是唯一入口。

### 3. AI把用户认成"银行理财"而不是券商——这是一个需要立刻修的工程bug

截图里"刘"这个角色的台词出现了银行理财相关的表述，和产品设定"是券商在用户按下确认之前的最后一次干预"直接矛盾。这不是文案问题，是大模型在长对话里发生了**上下文实体漂移**——这类bug通常出现在system prompt只在开局注入一次场景实体（账户类型、机构名、金额），随着对话轮数增加、大模型自己的生成内容进入上下文，关键实体信息被稀释甚至被模型自己的错误生成"带偏"。建议：

- 在 [`app/scenario.py`](https://claude.ai/epitaxy/app/scenario.py) 每一轮的prompt组装里，把"这是证券账户/银证转账场景，转出方是本人同名账户，不是银行理财产品"这类关键实体做**轮次级别的重复注入**，而不是只在开局说一次；
- 补一条离线的一致性回归测试（类似 [`tests/test_materials_copy.py`](https://claude.ai/epitaxy/tests/test_materials_copy.py) 那种"进CI的具体断言"思路），跑几百轮采样对话，正则扫描"银行理财""存款""理财经理"这类不该出现的词，一旦命中就说明场景实体在漂移，这个测试成本不高，但能把这类偶发bug从"同事玩到才发现"变成"提交前CI就拦下"。
- "发言不连贯"大概率是同一个根因（上下文管理，或者是网关超时后兜底台词和模型台词衔接生硬）——可以顺手查一下 [`docs/CONTEST.md`](https://claude.ai/epitaxy/docs/CONTEST.md) 第七节提到的 `line_sources` 监控（model/fallback/absorbed），如果 fallback 比例在那几局里偏高，说明是网关超时导致兜底台词频繁介入，衔接生硬是必然的，这个可以用 `/healthz` 直接验证，不用靠猜。

## 五、产品年轻化与视觉重塑：怎么做"炫酷"而不失分寸

这一段说说自由发挥的部分。年轻化不等于蹭梗、不等于游戏化，这个项目的题材本身决定了它承受不起"看起来像个游戏"的观感风险——反诈产品一旦视觉语言过于娱乐化，容易在评委和真实用户两端都引发"这是不是在消费严肃议题"的质疑，这也是GPT报告特别点名警示"不应照搬50%炸弹决胜"的原因。

**我建议的年轻化路径，不是往热闹的方向走，是往"精致的紧张感"方向走**：

- **视觉基调：借鉴第一名的暗色专业终端美学，而不是第二名的赛博游戏美学**。现在的界面走的是"仿真App截屏"的克制路线（appbar、系统状态栏、通用UI组件），这个选择本身是对的——[`docs/POSITIONING.md`](https://claude.ai/epitaxy/docs/POSITIONING.md)明确否决了"通用界面风格建议"，理由是"界面照搬微信/企业微信是所有设计决策的根，骗局本来就发生在聊天软件里"，这条护城河要保留。但在"确认转出"到"被拦下"这几个关键转场，可以把动效做得更有心跳感——现有的 `.transfer-alarm` 边缘警示晕染已经有一版雏形，可以强化成更有质感的一次"警报感"过渡，参考的不是游戏特效，是真实金融App风控拦截时那种克制但明确的红色警示语言，这样既年轻、又不失分寸。
- **触感与声音反馈**：年轻用户对细腻的微交互反馈期待值很高，这也正是GPT报告P0-3建议里"轻动画和声音反馈"想要的效果。在角色对调那一刻、在结局揭晓那一刻，加一次极短的震动反馈（H5 Vibration API即可），成本几乎为零，但沉浸感提升明显。
- **分享卡视觉对齐"测试类"内容的社交语言**：现在小红书、朋友圈上传播最广的自测内容（人格测试、防诈骗测试、反应速度测试）都有一套用户已经很熟悉的视觉语法——一句反差感强的结论 + 一个可视化对比条 + 一个"测测你自己"的召唤。分享卡现有的"差2倍"主角选择已经踩在这条线上了（[`static/history.js`](https://claude.ai/epitaxy/static/history.js) 的 `cardHero()`），建议把这套视觉语言做得更彻底、更像这类内容而不是像一张业务海报——但内容底线不变：**卡上的每一个数字仍然只能是真实跑出来的数据，不能为了好看编一个**。
- **不追热点梗，追真实场景的年轻化**：六个场景里刷单返利、虚拟币量化本身就是年轻人高发的骗局类型，这才是最大的"年轻化"杠杆——不需要额外蹭网络热梗给自己招致"拿反诈开玩笑"的风险，场景本身的真实感已经是最好的年轻化素材。

## 六、这不只是为了赢比赛：把赛期数据变成四级授权路线的第一块砖

站在高管的角度，这份材料最容易被浪费的地方是：赛期结束、名次出来，这套东西就被归档进"内部创新赛作品"，没有人再看第二眼。这是最可惜的结局，因为 [`docs/POSITIONING.md`](https://claude.ai/epitaxy/docs/POSITIONING.md) 已经把从demo到真正业务落地的路径想得很细——四级授权（0级赛期证据、1级自愿入口、1.5级影子模式、2级小流量对照），每一级只需要谈一件事，互不依赖。

**赛期本身就是免费拿到第1级证据的窗口**。建议明确把这次大赛的运营动作，同步当成产品验证动作来做：

1. **GPT报告P1-1建议的"30人冷启动测试"值得认真做**：不是走个形式，是真正记录"5秒能不能说清玩法、首次输入耗时、60/90秒完成率、短体验转完整十轮的转化率、分享卡生成率与最早退出节点"这几个数字。这些数字赛期内免费拿到，将来找风控合规条线要授权的时候，就是"已经有第一批完成率"的实证，而不是空口画饼。
2. **认真落实CONTEST.md里S9那条"拉一位风控/合规条线同事"**——这不只是给单人参赛补背书，展示页评论区是这个项目目前唯一能公开留痕的背书渠道，一条来自业务条线、具名、具体的评论，价值远超过二十张票。
3. **赛后把这套"60~90秒体验局"直接沉淀为第7步"自愿入口"的候选设计方案**，不用重新设计一遍——大赛版本本身就是最真实的一次低成本试跑。

## 七、落地优先级

| 优先级                                   | 内容                                                         | 解决什么                                                     |
| ---------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **P0（赛期内，工作量小、直接提升转化）** | 新增60~90秒体验局入口（双入口，不阉割完整模式）；把"同一句话换个时候说"的效力对比提前到第一次发言后演示；用非泄题的情绪反馈+轻动效/震动替代沉默等待；primer阶段加方向性提示（不给具体台词）；修复AI场景实体漂移bug并补一条自动化回归检查 | GPT 20维评分里最低的三项：参与门槛4/10、首分钟价值兑现4/10、即时反馈5/10；同事反馈的"绕弯子""词穷""角色认知bug" |

## 八、三条不做的事——护住已经想清楚的护城河

改进方案写多了容易变成"什么建议都往里加"，这里要反过来明确划线，这也是这份材料里我最想替产品所有者守住的部分：

1. **不做逐轮候选句选择题**，也不做随机赌博式的决胜机制——这两样东西看似能降门槛、提爽感，实际上会直接抹掉这个项目在三个第一名里唯一不可复制的资产：判分是确定性的、对手是活的。
2. **不为了赛期热闹把项目做成社区、工具箱或排行榜堆砌**——GPT报告P2说得很清楚，"获奖前不建议扩展社区、排行榜或更多工具，先把体验漏斗打通"，第三名的路线是他们的护城河，不是我们的。
3. **不为了体验流畅而悄悄把expert难度调低，也不把任何模拟数据包装成"已验证有效"**——[`docs/CONTEST.md`](https://claude.ai/epitaxy/docs/CONTEST.md)第八节那三条硬边界（没有法定义务、效果没验证过、机制有实证但不等于已拦下转账）在这次改版里必须原样继承，这是这个项目目前唯一站得住脚的诚实感，也是它在一堆"泛财经类应用"里最值钱的信用背书。
