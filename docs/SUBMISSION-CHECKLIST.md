## 三、部署当天

```bash
./package.sh            # 不设 PACKAGE_INCLUDE_SECRETS，密钥不进包
```

- [ ] 产物文件名**不带** `-WITH-SECRETS-DO-NOT-UPLOAD`（带了就是拿错包了，重打）
- [ ] 服务器已装 Python 3.10+（CentOS 7.9 自带 3.6）
- [ ] 密钥放在 `~/.ai-antifraud-persuasion/env`，不在 ZIP 里
- [ ] `./stop.sh && ./install.sh && ./start.sh` 走一遍，**读 start.sh 的输出**，
      它会自己把下面三件事印出来：

| start.sh 印了什么 | 意思 | 怎么办 |
|---|---|---|
| 大模型网关探测失败 | 打不通内网网关 | `env` 里 `LLM_PROVIDER=public`，重启 |
| 没有配退路（ADR-0007） | token 用尽那天接不住 | 填 `PUBLIC_LLM_BASE_URL/API_KEY/MODEL`，重启 |
| 退路本身探不通 | 现在没事，**用尽那天会连着失败两次** | 核对 `PUBLIC_LLM_*` 三个变量与账号余额 |

- [ ] 手动确认一次：`curl -s 'http://127.0.0.1:21818/healthz?probe=1'`
      → `llm_probe.ok` 与 `llm_probe_fallback.ok` **都要是 true**
- [ ] 平台若用 iframe 嵌展示页：`env` 里填 `FRAME_ANCESTORS=<平台域名>`，
      否则「作品展示」页签是一块空白（默认仍是 `'none'`）
- [ ] **把展示页 URL 填进 `static/index.html` 的 `<meta name="af-share-url">`**
      （CONTEST-POSITIONING §六 S2 拍板：二维码指向展示页，那是唯一同时能
      "看懂"和"投票"的页面）。**静态文件实时读盘，改完刷新即可，不用重启**
- [ ] 填完扫一次那个码，确认真的落在展示页上

## 四、被问到时的三条硬边界

**这三条不许含糊，含糊比说"没有"更掉分。**

| 问 | 答 |
|---|---|
| 券商有法定劝阻义务吗 | **没有。** 《反电信网络诈骗法》全文未点名证券公司，罚则也不含（[EVIDENCE §一](EVIDENCE.md)）。这是主动做的，推力是投诉与声誉：某券商 2025 年假冒案件线索超 1900 条、同比 +280%、总部来访受害者 150 人次 |
| 效果验证过吗 | **没有。** 24h 内转出放弃率一次都没量过——它需要接进真实异动流水。现在有的是**口径与对照组设计**，不是结果 |
| 角色对调有依据吗 | **机制有同行评议的实证支持**（CHI 2026 ROLESafe，n=144，"去劝受害者"组识别 F1 0.85 最高）。但那篇的结局变量是**诈骗线索识别能力**，不是"取消了一笔正在进行的转账"——**不能说"已被证明能拦下转账"** |

同理，材料里**不出现**：已验证有效 / 降低 X% / 依据某法本公司必须 / 这是某平台的官方产品。
