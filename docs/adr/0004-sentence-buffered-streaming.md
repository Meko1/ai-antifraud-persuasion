# 按句缓冲下发，而非逐字流式

台词以句号、问号、感叹号为界攒满一句，经输出安全层校验后整句下发，而不是逐字符透传模型输出。

逐字流式与输出过滤在时序上不可调和：字一旦到达用户屏幕，再发现整句违规就已经晚了，而决赛是现场直播，截图比删除快。按句缓冲把过滤放在下发之前，使拦截率成为确定值而非概率值。

代价是牺牲逐字的丝滑感，但逐句蹦出的观感更接近真人在即时通讯里连发数条消息，对本作品而言是升级而非妥协。

## Consequences

- 单句长度上限需要兜底：模型若长时间不产出句末标点，达到字符阈值即强制切分下发，避免观感卡死。
- 安全层可以做整句级别的替换（命中即整句换成角色兼容的兜底台词），不必处理半句被截断的情况。
- 首字延迟从"首个字符"变为"首句完成"，需在提示词中要求劝阻对象开口即短句。
- 现有骨架 `app/main.py` 的 `/api/demo/stream` 是逐字下发的验证用端点，正式对局端点不沿用其粒度。
